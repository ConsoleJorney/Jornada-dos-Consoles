#  Jornada dos Consoles

**Jornada dos Consoles** é um site informativo desenvolvido com HTML, CSS e JavaScript, voltado para apresentar informações sobre consoles de videogame, suas gerações e evolução ao longo do tempo.

---

##  Sobre o projeto

O projeto tem como objetivo organizar e exibir conteúdos relacionados ao mundo dos consoles de forma simples, visual e acessível. Ele foi desenvolvido como prática de desenvolvimento front-end, focando em estruturação de conteúdo e interface de usuário.

---

##  Conteúdo abordado

O site apresenta informações como:

- História dos consoles de videogame
- Evolução das gerações de consoles
- Características principais de diferentes plataformas
- Curiosidades do mundo dos games

---

##  Tecnologias utilizadas

- HTML5  
- CSS3  
- JavaScript (Vanilla)

---

##  Objetivo do projeto

O objetivo é praticar desenvolvimento web front-end, com foco em organização de conteúdo, estrutura de páginas e criação de interfaces informativas utilizando tecnologias base da web.
